# 用友ERP 生产演示系统

**一个 HTML 文件，把「ERP 生产流程」从订单讲到发货。** 双击就能用，不联网、不装环境、不用服务器。

```
用友ERP生产演示系统/          ← 独立的一级 git 仓库（main 分支）
├─ 用友ERP生产演示系统.html   ← 全部内容都在这一个文件里
├─ README.md
├─ .gitignore
└─ .gitattributes             ← 统一 LF 换行
```

---

## 一、怎么打开

双击 `用友ERP生产演示系统.html`，用 **Chrome** 或 **Edge** 打开即可（推荐把窗口最大化）。

- 不需要联网，可以拷到 U 盘 / 直接发微信，断网课堂上照样跑。
- 不需要装任何软件、不需要起本地服务，文件放在哪都能开。
- 右上角两个按钮：`♪ 音效开` 开关答题提示音；`缩放 xx%` 按窗口宽度自动缩放，让 100% / 125% / 150% 显示缩放的电脑看到同一套版面。

## 二、六个页签＝六站，按讲课顺序排好

顶部导航从左到右就是建议的讲课顺序：**先看全局 → 再看料 → 再动手做四个游戏**。

### ① 生产流程演示（全局）
一台挂钟从客户下单到发货，ERP 里要走 **15 步**：销售订单 → 销售预测 → MPS 主生产计划 → MRP 运算 → 采购订单 → 到货入库 → 生产订单 → 领料 → 委外发料 → 委外收货 → 加工 → 总装 → 完工入库 → 发货。

每一步都同步三样东西：**流程图走到哪个环节、这一环节产生什么单据（单号 / 部门 / 来去向）、下方物料流动看板里三个仓库的库存怎么变**。适合上课时先完整播一遍，让学生建立"单据跟着业务走"的直觉。

- 按钮：上一步 / 下一步 / 重播本步 / 自动播放 / 同屏演示 / 重置
- 快捷键：`←` `→` 切步，`空格` 播放下一步，`0`–`9` 直跳，`R` 重播本步，`D` 同屏演示
- 点看板上的任意节点可以直接跳到对应环节

### ② 物料图·提前期（再看料）
把 BOM 结构和**提前期**画在同一张时间轴上：交期在最顶上，时间向下走，每个物料一个方框，方框中心落在它的"完成期"上，从框底拉一条竖线到"开工/下单日期"—— 这条竖线的长度就是提前期。

一眼能看出：**谁必须先动手、谁可以晚点动**；周末（非工作日）用红色横带标出来，自制件按工作日倒排、采购件/委外件按自然日倒排的区别也标在格子上。

### ③ BOM 搭建（第一个游戏）
左边是一张**空白的 BOM 结构图**（只有层级和连线），右边是 13 张物料卡。学生要把卡拖进空槽，把整机的 BOM 搭出来。

- 空槽的**方框颜色＝这一格需要的物料类型**：M 蓝＝自制、B 橙＝采购、S 绿＝委外
- 判定按类型：只要类型对上就算放入，放错会提示并计一次失误
- 铝材要放 3 处、塑料要放 2 处 —— 一张卡可以填多个格子，卡上写着「还需 N 处」，放到 0 就置灰
- 填好的格子还能再拖动调整；放满 16 格自动结算：准确分 50 + 速度分 50 − 失误扣分
- 结算页会给出**标准 BOM 对照表**：能通过判定 ≠ 账目正确，同名物料放错父件也能过，对照表用来纠这个偏

### ④ 属性辨识（第二个游戏）
一张物料卡弹出来，判断它属于哪一类：**本厂自己做（M）/ 向供应商买（B）/ 发料给委外商做（S）**。

- 键盘 `1` `2` `3`（或 `←` `→` 选、`Enter` 确认）就能玩，也可以用鼠标拖
- 答错会解释为什么，比如"机芯是买回来的成品件，不是自己做的"
- 共 10 题，答完给准确率与漏判清单

### ⑤ 入库归仓（第三个游戏）
做完的料该进 **01 原辅料仓 / 02 半成品仓 / 03 成品仓** 哪个仓？把料拖进对应的仓库大门。

- 陷阱是：**采购件不一定进原辅料仓** —— 机芯、电池是买回来的，但它们是直接上总装线的半成品，进 02 仓
- 拖对了仓库门会变绿，拖错会变红并说明理由
- 计时评分：40 秒内满分速度分，超时递减；每错一次扣 2 分，最多扣 20

### ⑥ 排产闯关（第四个游戏）
在 2.5D 厂区里走动作业员：走到采购部 / 生产车间 / 委外商 / 三个仓库门口，按 `Enter` 进楼开工。

- 目标是按**倒排的最晚开工日**把 17 项作业排完，赶在 **09-26 交期**前交出 **400 台**
- 左上角「今日计划」会实时告诉你今天该开哪几项、未完成几项、距交期还剩几天
- 空格推进一天；`P` 查计划表；`方向键 / WASD` 移动
- 右侧四个面板：操作说明 / 提前期速查 / 在制在途 / 作业日志，方便讲"为什么这一天必须开工"

## 三、里面用的是什么数据

| 项目 | 取值 |
| --- | --- |
| 成品 | 电子挂钟 `10000`，1 台 = 1 个 |
| 订单 | `0000000002`，400 台，交期 **2019-09-26（周四）** |
| 物料 | 14 个物料 / 5 个层级 |
| 类型分布 | 自制 M × 7、采购 B × 5、委外 S × 2 |
| 仓库 | 01 原辅料仓、02 半成品仓、03 成品仓 |
| 供应商 / 委外 / 客户 | 供应商、宏达注塑（委外）、客户华美商贸 |

物料类型（M / B / S）就是 ERP 里"物料属性 / 采购类型"那一栏：

- **M 自制**：本厂自己加工 / 装配（钟盘、指针、盘面、字膜、成品…）
- **B 采购**：向供应商买回来（机芯、电池、铝材、塑料、薄膜…）
- **S 委外**：本厂发料给委外商做好再收回来（盘体、钟框）

## 四、适配与实测

- 版面按 **1900 × 983** 设计，浏览器里按窗口宽度整体缩放，所以 100% / 125% / 150% 显示缩放的电脑看到的是同一套版面，只是整体大小不同。
- 实测 **1366×768 / 1600×1000 / 1920×1080** 三档：六个页签都能一屏放下，没有外层滚动条，控制台零报错。

## 五、技术说明（维护时看）

- **单文件**：HTML + CSS + JS 全部内嵌，没有任何外部字体、图片、脚本、网络请求；图形（流程图、BOM 图、2.5D 厂区）都是代码画出来的，不是图片。
- **结构**：顶部导航 + 6 个视图。前两站（生产流程演示、物料图）是 iframe，源码放在页面底部 `<template>` 里，切到该页时才灌进 `srcdoc`——这样两三套 CSS / 脚本天然隔离，互不污染，页面状态在第一次打开后一直保留；后四站和主文档在同一页里直接切换。
- **音效**：Web Audio 现场合成（没有音频文件）。答对是上行琶音，答错是低频下坠。
- **想改数据**：BOM / 提前期 / 库存在前两站的脚本开头集中定义；四个游戏各自的题库、仓库归属、作业表也在各自那一段的开头，都有中文注释。

## 六、已知限制

- 只在 **Chrome / Edge** 上验证过（课堂电脑基本都是这两个）。Firefox / Safari 未测。
- 为投影和电脑屏设计，**手机上基本没法用**（版面会缩得很小）。
- BOM 搭建的判定是**按类型**（M / B / S）而不是按料码，同一类型的空位可以互换。这是有意的教学取舍——先让学生分清"哪些是买的、哪些是自己做的、哪些是发外协的"；纠正偏差靠结算页的标准 BOM 对照表。
- 排产闯关里的日期、库存、提前期都是写死的演示数据，不是实时排产结果。
